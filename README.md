# CommonTongue
A world of warcraft addon that removes the language barrier from play. Set your target language and unlock new friendships around the world.

> Status: milestone M4 (protocol + composer). The addon translates common LFG /
> trade / raid / courtesy lines between English, German, and Spanish, and can
> send exact phrase IDs between two CommonTongue users (`/ct compose`). German
> and Spanish data are unreviewed drafts. Free-form chat is not translated.
